# DevMind 🧠

**DevMind** is a high-performance, AI-integrated full-stack platform designed to serve as a "Developer's Second Brain." It leverages cutting-edge generative AI to provide intelligent insights, automated workflows, and data-driven decision-making for modern development teams.

---

## 🚀 Key Features

- **AI-Powered Intelligence**: Seamlessly integrated with **Google Gemini AI** for advanced natural language processing and code analysis.
- **Modern Full-Stack Architecture**: Built with a decoupled architecture for maximum scalability and performance.
- **Real-Time Responsiveness**: A blazing-fast frontend powered by **React 19** and **Vite**.
- **Robust Persistence**: Secure and scalable data management using **MongoDB** and **Mongoose**.
- **Sleek Aesthetics**: Styled with **Tailwind CSS 4** for a premium, developer-centric UI/UX.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 (Latest)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 4 (Beta/Latest)
- **API Client**: Axios

### Backend
- **Runtime**: Node.js
- **Server**: Express.js
- **AI Engine**: Google Generative AI (Gemini SDK)
- **Database**: MongoDB (Mongoose ODM)

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas or local instance
- Google AI API Key (Gemini)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/DevMind.git
   ```

2. **Setup Server**
   ```bash
   cd server
   npm install
   # Create a .env file with your GEMINI_API_KEY and MONGO_URI
   npm start
   ```

3. **Setup Client**
   ```bash
   cd client
   npm install
   npm run dev
   ```
